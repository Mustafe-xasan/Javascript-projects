# 🧮 Calculator App

A clean and fully functional calculator built with **JavaScript, HTML, and CSS**. Supports basic arithmetic operations with a user‑friendly interface.

---

## 📖 Description
This project is a standard calculator that allows users to perform addition, subtraction, multiplication, and division. It handles decimal inputs, prevents division by zero, and limits the display length for long results. The design uses a dark theme with a background image and smooth button animations.

---

## ✨ Features
- ➕ Addition  
- ➖ Subtraction  
- ✖️ Multiplication  
- ➗ Division  
- ⌨️ Clear all (C button)  
- 🔢 Decimal point support  
- ⚠️ Error handling for division by zero  
- 📏 Auto‑truncation of long results (10 characters max)  

---

## 🧠 Concepts Used
- 🧩 DOM manipulation (`getElementById`, `innerHTML`)  
- 🖱️ Event handling with `onclick` attributes  
- 🔁 State management (`currentInput`, `firstNum`, `operator`)  
- 🧮 Floating‑point arithmetic  
- 🎨 CSS Grid layout and responsive design  
- ✨ CSS transitions and hover effects

## 🚀 How to Run
1. Clone or download the project folder.  
2. Make sure the `assets/bg.jpg` exists (or update the CSS background image path).  
3. Open `index.html` in any modern web browser.  
4. Start clicking buttons – the display updates in real time.  

---

## 📌 Project Goal
This project was created to practice **basic JavaScript logic, handling user input, and building a functional UI from scratch** without using `eval()`. It reinforces understanding of state, event handling, and DOM updates.

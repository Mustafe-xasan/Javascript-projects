## 🚀 Getting Started

1. **Clone the Repo:**

```bash
git clone https://github.com/Mustafe-xasan/Javascript-projects.git
cd Javascript-projects
```

2. **Install Dependencies:**

```bash
pnpm install
```

3. **Run Dev Environment:**

```bash
pnpm dev
```
